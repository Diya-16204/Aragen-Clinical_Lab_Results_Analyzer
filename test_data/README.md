# Kaggle dataset requirement

The assignment requires the Kaggle **Laboratory Test Results - Anonymized Dataset**. Download the dataset and place its original CSV in this folder as `kaggle_laboratory_results.csv` before submission. Preserve the source file and record its Kaggle URL in the README.

The three other CSV files are synthetic demo fixtures required for quick Normal, Warning, and Critical demonstrations. The dashboard importer expects `test_name,value,unit` headers; if the Kaggle source uses different column names, create a documented mapped export with those headers.
